# PAYA 💸

A full-stack mobile wallet app — send money, fund your wallet, track transactions.

## Stack
- **Mobile:** React Native (Expo) + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **Database:** PostgreSQL (Neon) + Prisma
- **Auth:** JWT
- **Payments:** Paystack
